# STYLE — exam graphics (tile, 1:1)

Shared style for all exam tiles. Each prompt inlines the anchors; the full
definition is here.

## Philosophy
Realistic, soft painterly veterinary illustration — the same as patients
(art/prompts/STYLE-GUIDE.md). No blood/gore, child-appropriate. Tile legible
even small (200px).

## Render
- Soft brush, warm texture, light grain.
- Composition: the exam subject + the veterinarian's hand/tool in frame.
  Medium-close.
- Background: solid, soft, lightly blurred (warm cream/sage) — no room detail,
  so the tile stays legible.
- Accent color: clinical teal (#26827e) on tools/skin.

## Requirements
- 768×768 (1:1 square tile) for the 2-column exam grid.
- No text, logo, watermark, collage, split panels.
- No blood, pus, gore. A minor wound is OK (red scrape, no weeping).
- A gloved (light-blue) veterinarian's hand where sensible — teaches the
  clinical context.
